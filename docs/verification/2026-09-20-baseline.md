- [Next static export](https://nextjs.org/docs/app/guides/static-exports): host exported files; request-time server features require another architecture.
- [Cloudflare Workers Static Assets](https://developers.cloudflare.com/workers/static-assets/) and [routing](https://developers.cloudflare.com/workers/static-assets/routing/worker-script/): exported frontend plus explicit API handling.
